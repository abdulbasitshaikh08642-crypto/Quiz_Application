# Quiz Application Website

A beginner-friendly Flask quiz website with SQLite-backed categories, question management, quiz history, and score summaries.

## Features

- Homepage with quiz categories
- Multiple-choice questions with four answer options
- Score calculation, result page, and unanswered handling
- SQLite database for categories and questions
- Add, edit, and delete question management
- Search and filter question records
- Quiz history and saved scores
- Mobile-responsive layout

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000 in your browser.
